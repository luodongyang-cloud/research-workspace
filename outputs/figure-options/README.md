## Scientific brief

Light history establishes volatile photoconductance G; capacitor C independently stores electrical weight V_C. Sensing is at zero externally applied sensor bias. Weight writing uses TG1 ON and TG2 OFF, fixed V_in and variable write duration. Readout uses TG1 OFF and TG2 ON, applying nonzero V_C to the sensor. The G and V_C matrices feed an elementwise multiplication followed by current summation. One weight template corresponds to one scalar output.

## Review boundary

The concepts explore spatial hierarchy, chip rendering, palette and panel composition. Generative drawing may introduce simplified or inaccurate pixel wiring and qualitative trace shapes. In particular, decorative pixel circuits do not define the actual TG topology; detailed wiring belongs in Fig. 3. Optical pulses, conductance, read voltage and read current must be rebuilt from one consistent conceptual time model before a publication version is prepared. No measured data, performance claims or confirmed fabrication stacks are represented. Author scientific review and journal-specific AI-art eligibility checks remain required.
